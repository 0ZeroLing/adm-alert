ADM 预警系统

团队共享版 · 目标 ADM ≥ 4.1 · 军事/工业每天衰减 25%（按小时均摊 ≈1.04%/h）· 战略不自动衰减 · 数据存云端，多人多设备互通
ADM = 1(基础) + 军事 + 工业 + 战略系数（首都 +2） 剩余 = 军事/工业同时衰减下距 ADM 跌破目标的小时数 预警 = 剩余 < 缓冲（一级 25+R h / 二级 50+R h），R 按每个星系自己的数据时间独立计算
暂无星系数据。
机制：等级指数达 100% 升级，归 0 降级。军事/工业按每天 25% 衰减（按小时均摊 25/24 ≈1.04%/h，24 小时累计 25%）。
每个星系有独立的数据时间：成员 A 今天 10 点更新的星系和成员 B 昨天 22 点更新的星系各按自己的时间外推衰减。编辑星系时可填「数据时间」（默认现在）；不填就按保存时刻算。
预警含义（设某星系数据更新于 H 点，剩余 R = 24 − H）：模拟军事/工业同时逐小时衰减，找 ADM 首次跌破目标的时刻——剩余 < 25 + R 小时触发一级（一天衰减+当日剩余就跌破）；剩余 < 50 + R 小时触发二级（两天内跌破）。缓冲随时间流逝递减（19 点更新时即 30/55 小时）。战略按当前等级固定计算，不衰减、不降级。
「触发项」= 跌破那一小时发生降级的项目（军事/工业/两者同时）。团队数据每 60 秒自动从云端刷新，任何人的修改全员可见。
